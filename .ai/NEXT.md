# NEXT — Planned Features

This document outlines planned features and improvements for future releases of Gantt Editor.

## v1.1.0 — Enhanced Editing (Next Release)

### High Priority
- [ ] **Copy/Paste bars** (Ctrl+C / Ctrl+V)
- [ ] **RGB color picker** — replace fixed palette with full color wheel
- [ ] **Custom color palettes** — save and load color schemes
- [ ] **Recent files list** — quick access to last opened projects
- [ ] **Auto-save** — periodic background saves to prevent data loss
- [ ] **Keyboard shortcuts panel** — help overlay showing all shortcuts

### Medium Priority
- [ ] **Bar list panel** — sidebar showing all bars with search/filter
- [ ] **Multi-select bars** — select multiple bars for batch operations
- [ ] **Toolbar redesign** — move frequently used controls to top toolbar
- [ ] **Design tokens file** — extract colors, sizes, spacing to separate config

### Low Priority
- [ ] **Connection styles** — different arrow types (straight, curved, stepped)
- [ ] **Grid snapping options** — configure snap points (quarters, thirds, etc.)
- [ ] **Custom row heights** — set different heights per row

## v1.2.0 — Visualization & Export

### Planned Features
- [ ] **"Today" line** — vertical indicator for current date
- [ ] **Color legend** — show what each color represents
- [ ] **Bar grouping** — collapsible groups (e.g., by building, team, phase)
- [ ] **Milestones** — diamond-shaped markers for key dates
- [ ] **Print support** — optimized layout for printing
- [ ] **Export to SVG** — save diagram as vector graphics
- [ ] **Export to PNG/PDF** — rasterized exports
- [ ] **Custom grid backgrounds** — patterns, alternating colors

## v2.0.0 — Collaboration & Advanced Features

### Big Ideas
- [ ] **Real-time collaboration** — multiple users editing simultaneously
- [ ] **Comments & annotations** — attach notes to bars and dates
- [ ] **Timeline views** — different granularities (days, weeks, quarters, years)
- [ ] **Critical path analysis** — highlight longest dependency chain
- [ ] **Resource allocation** — assign people/resources to bars
- [ ] **Progress tracking** — show completion percentage on bars
- [ ] **Baseline comparison** — overlay original plan vs actual progress
- [ ] **Calendar integration** — sync with Google Calendar, Outlook
- [ ] **Templates** — pre-made project templates (construction, software, events)
- [ ] **Version history** — browse and restore previous project states

## Future Considerations

### Performance
- [ ] Virtual scrolling for large projects (1000+ bars)
- [ ] WebGL rendering for complex diagrams
- [ ] Web Worker for layout calculations

### Accessibility
- [ ] Full keyboard navigation
- [ ] Screen reader support
- [ ] High contrast mode
- [ ] Configurable font sizes

### Platform
- [ ] Desktop app (Electron/Tauri)
- [ ] Mobile web version
- [ ] API for programmatic access
- [ ] Embed mode for integration into other apps

---

**Note**: This is a living document. Features may be reprioritized, added, or removed based on user feedback and development constraints.
